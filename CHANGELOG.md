# Changelog

## 1.1.0 — Widgetly: полная переработка

Исправлено
- Режим «выбрать виджет → нажать на область» не работал: клик по области не вызывал размещение.
- Часы не тикали (время рисовалось один раз).
- На экранах 561–900 px (планшеты) нельзя было открыть каталог и настройки; на телефоне не открывались настройки.
- Ползунок «Размер текста» почти ничего не менял: размеры шрифтов внутри виджетов были заданы жёстко.
- Изменение размера областей не попадало в историю, а каждое движение ползунка засоряло её отдельным шагом — теперь такие правки объединяются.
- Ctrl+Z / Delete срабатывали во время набора текста в полях настроек.
- В режиме просмотра области выделялись, а разделители двигались; не было выхода кроме кнопки и не было полноэкранного режима.
- Погода, «События», «Уведомления» и «Мировое время» показывали выдуманные данные — теперь реальная погода и часовые пояса, редактируемые списки.
- Повреждённые данные в `localStorage` могли сломать приложение — теперь они проверяются и исправляются.
- Иконки деления были перепутаны с направлением деления.
- `engines.node >=20.19` не подходил для Capacitor 8 (нужен Node 22+); убрана удалённая опция `bundledWebRuntime`; версии зависимостей заданы диапазонами вместо непроверяемых точных.
- Нет учёта безопасных зон (вырез / системные панели Android).

Добавлено
- Календарь-месяц, акцентный цвет, подпись показателя, выбор городов мирового времени.
- Клавиатурное изменение разделителей, aria-подписи, подсветка цели при перетаскивании.
- Кнопка «Сбросить к шаблону» (с отменой).
- Модульные тесты модели, истории и конфигурации проекта.

Изменено
- Проект переименован в Widgetly; код разделён на модули (`model`, `history`, `storage`, `hooks`, `components/*`).
- Ключ хранилища `widgetly:v2` (старые сохранения несовместимы по формату и не импортируются).

## 1.0.1 — Clean Editor fix
- Исправлены кнопки деления областей, настройка GitHub Actions без npm-кэша.
