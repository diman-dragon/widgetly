# Продуктовая модель

Widget Editor — персональный визуальный конструктор информационного экрана.

Пользователь делит экран на области, меняет размеры областей и помещает в них виджеты. Каждый виджет можно выбрать и настроить. Готовый экран можно открыть в режиме просмотра.

Редактор не требует учётной записи и не предполагает серверной части.
