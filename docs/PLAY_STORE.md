# Публикация DataLaw Widgetly в Google Play

## 1. Технически (уже сделано в проекте)
- Capacitor 8 → compileSdk/targetSdk 36 (задаёт сам Capacitor), Java 21, Node 22.
- `appId`: `com.widgetstudio.app` (`capacitor.config.json`). **После первой публикации менять нельзя.** Если нужен другой (например, `com.datalaw.widgetly`) — поменяйте до первой загрузки; приложение с новым `appId` ставится отдельно от прежнего.
- Версия: `package.json → version` (это `versionName`); `versionCode` = номер запуска GitHub Actions — растёт сам.
- Адаптивная иконка (с монохромной версией для тем Android 13+), заставка (светлая/ночная), `allowBackup=false`.
- Debug-сборки из CI подписаны фиксированным ключом `native/android/debug.keystore` — так их можно ставить поверх друг друга. Для Play он не используется: туда идёт AAB, подписанный ключом загрузки.
- Подпись релиза берётся из переменных окружения; CI собирает подписанный AAB, если заданы секреты.
- Разрешения: `READ_CALENDAR` (необязательное, запрашивается кнопкой в настройках) и `RECEIVE_BOOT_COMPLETED`. Интернет-разрешение даёт сам Capacitor.

## 2. Ключ загрузки (один раз)
```bash
keytool -genkeypair -v -keystore upload.jks -alias upload -keyalg RSA -keysize 2048 -validity 10000
base64 -w0 upload.jks      # macOS: base64 -i upload.jks
```
Файл `upload.jks` и пароли храните вне репозитория (`*.jks` в `.gitignore`). В Play Console включите **Play App Signing**.
Секреты GitHub (Settings → Secrets and variables → Actions): `KEYSTORE_B64`, `KEYSTORE_PASSWORD`, `KEY_ALIAS` (`upload`), `KEY_PASSWORD`.
После push в `main` артефакт `datalaw-release-aab` — это файл для загрузки в Play Console.

## 3. Карточка приложения
Тексты — `docs/STORE_LISTING.md`. Графика — `assets/`:
- иконка 512×512: `assets/play-store-icon-512.png`;
- feature graphic 1024×500: `assets/feature-graphic-1024x500.png`;
- скриншоты телефона (2–8): сделайте с устройства — редактор в светлой и тёмной теме и виджет на рабочем столе.
Категория: **Personalization**. Шрифты: встроенные под лицензией SIL OFL 1.1 (`docs/licenses/`) — упомянуты в «О приложении». Реклама: нет. Целевая аудитория: 13+ / не для детей.

## 4. Политика конфиденциальности
Опубликуйте `docs/PRIVACY_POLICY.md` по публичному URL (GitHub Pages подойдёт), подставьте дату и e-mail, затем впишите URL в `PRIVACY_URL` (`www/js/app.js`) и в Play Console.

## 5. Форма Data safety (ответы по факту работы приложения)
| Вопрос | Ответ |
|---|---|
| Данные собираются/передаются | Да — только координаты выбранного пользователем города (и API-ключ, если пользователь сам его ввёл) уходят погодному сервису. Укажите **Approximate location**, цель — *App functionality*, не для рекламы и не для профилирования. Сверьтесь с актуальными определениями «collected/shared» в справке Play Console |
| Календарь | Читается (только выбранные календари) **только на устройстве**, чтобы показать события в виджете; никуда не отправляется, не сохраняется. Это «доступ без сбора» — не отмечайте как collected |
| Шифрование при передаче | Да (HTTPS) |
| Можно удалить данные | Данные хранятся локально; удаляются при удалении приложения или кнопкой «Сбросить все настройки» |
| Аккаунты, реклама, аналитика | Нет |

## 6. Прочие формы
- **Content rating**: анкета IARC — насилия/контента нет, итог «для всех».
- **Permissions**: `READ_CALENDAR` не входит в список ограниченных разрешений (как SMS/журнал звонков), отдельная декларация не нужна. Перед запросом приложение объясняет, зачем доступ.
- Для новых личных аккаунтов разработчика Google требует закрытое тестирование перед выходом в продакшен — проверьте текущие условия в Play Console.

## 7. Проверка перед релизом
- Android 8, 12, 14+; светлая / тёмная тема; Pixel и Samsung One UI.
- Виджет: растяжение, поворот, смена часового пояса, режим энергосбережения.
- Календарь: нет событий → блок скрыт; 1–2 события → без листания; 3+ → листаются по кругу; тап по событиям открывает календарь, тап по часам — часы.
- Выключенный экран: виджет ничего не перерисовывает; нет сети — остаётся последняя погода.
- Кнопка «Добавить на рабочий стол» при уже стоящем виджете **обновляет** его, а не создаёт второй.
