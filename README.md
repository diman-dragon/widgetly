# Widget Studio

Android-приложение (Capacitor) с одним настраиваемым виджетом: слева картинка с **часами, днём недели и датой**,
справа **погода** (город, страна, температура, описание, мин/макс) и **прогноз на 3 дня вперёд**.
Редактор — HTML/JS (`www/`), виджет, обновления и запросы — нативный Java (`native/android/`).

## Что настраивается
- **Внешний вид:** прозрачность виджета, скругление, рамка, фон слева (закат / ночь / своё фото / без картинки), затемнение, ширина левой части, цвета правой панели и текста, кнопка обновления ↻.
- **Часы, день недели, дата:** показывать/скрыть, формат, шрифт (10 системных семейств), размер, цвет, часовой пояс часов.
- **Погода:** источник, город (поиск), единицы °C/°F, число дней прогноза (0–3), интервал обновления (6/12/24 ч), что показывать, шрифт, размер.
- **Источники погоды:** Open-Meteo (по умолчанию) и MET Norway — без регистрации и ключей;
  OpenWeatherMap и WeatherAPI.com — со своим API-ключом (кнопка «Проверить» в редакторе).
- Предпросмотр 5×3 (по умолчанию), 4×3, 5×2, 4×2 — рисуется тем же кодом, что и сам виджет.
- Шестерёнка: тема приложения (светлая/тёмная/системная), версия, политика конфиденциальности, сброс.

## Как обновляется
- **Часы** — системный `TextClock` в виджете: каждую минуту сам, без запуска приложения (секунд нет).
- **Дата и день недели** — раз в сутки, на первом «тике» с включённым экраном после смены дня.
- **Погода** — **не чаще раза в 6 часов** (можно реже: 12/24). Один запрос приносит и текущую погоду, и прогноз. Смена города/источника/ключа даёт новый запрос.
  При ошибке сети остаётся последняя погода, повтор не чаще раза в 10 минут.
- **Кнопка ↻** перерисовывает виджет и обновляет дату; погоду — только если кэш старше интервала.
- При выключенном экране ничего не обновляется: «тик» — неточный **не-wakeup** `AlarmManager` раз в 5 минут, устройство не будится. Точные будильники не нужны.

## Структура
| Путь | Что это |
|---|---|
| `www/` | Интерфейс редактора (чистые ES-модули, без сборщика) |
| `native/android/java/` | `Renderer` (рисование), `Updater` (политика обновлений), `WeatherService` (4 источника + кэш), `WidgetPlugin` (мост), ресиверы |
| `native/android/res/` | Макет виджета (`TextClock` ×10 шрифтов), иконка приложения, описание провайдера |
| `scripts/setup-android.js` | Генерирует `android/`, копирует `native/`, патчит манифест и версию |
| `.github/workflows/android.yml` | Сборка APK/AAB в GitHub Actions |
| `docs/` | Чек-лист публикации в Google Play, политика конфиденциальности |

## Сборка только с VS Code + git
1. `git init`, коммит, `git push` в ветку `main` на GitHub.
2. **Actions → Android build** → артефакт `widget-studio-debug-apk` → установить на телефон.
3. Для Google Play — секреты `KEYSTORE_B64`, `KEYSTORE_PASSWORD`, `KEY_ALIAS`, `KEY_PASSWORD`; подробности в `docs/PLAY_STORE.md`.

Локально (Node 22+, JDK 21, Android SDK): `npm install && npm run android:setup && cd android && ./gradlew assembleDebug`.
Быстрая проверка вёрстки в браузере: `npm run web` (картинку рисует только Android-версия).

## Перед публикацией
- `appId` в `capacitor.config.json` (после публикации менять нельзя) и `PRIVACY_URL` в `www/js/app.js`.
- Иконка приложения уже есть (адаптивная, `native/android/res`); 512×512 для магазина — `assets/play-store-icon-512.png`.

## Ограничения
- Тап по виджету открывает приложение (отдельных зон нажатия нет).
- Иконки погоды — системные эмодзи; их вид зависит от версии Android.
- Свой шрифт `.ttf`: нужен `res/font`, расширение `Renderer.tf()` и ещё один `TextClock` в `widget_root.xml`.
