# Widgetly

Гибридное приложение для создания и настройки виджетов часов и погоды на Android.
Capacitor (редактор на React) + Kotlin (нативный виджет и мост).

## Как это устроено

- **Редактор** (`web/`) — React + TypeScript. Создаёт JSON-дизайн, показывает SVG-превью.
- **Виджет** (`android/`) — Kotlin. Читает тот же JSON и рисует его в Bitmap (`DesignRenderer.kt`).
- **Мост** — Capacitor-плагин `WidgetBridge` (`WidgetBridgePlugin.kt`): сохранение дизайнов, закрепление виджета, погода, диагностика.
- Формат дизайна описан в `web/src/design/types.ts`. Форматирование дат и погоды зеркально в `format.ts` и `TextFormat.kt`; тесты проверяют одни и те же значения.

## Первый запуск: пуш и APK

1. Создайте репозиторий на GitHub и запушьте содержимое папки.
2. Откройте вкладку **Actions**: сборка `CI` запустится сама.
3. Когда она завершится, скачайте артефакт `widgetly-debug-apk` (внутри `app-debug.apk`), установите на телефон (разрешите установку из неизвестных источников).
4. Debug-APK подписан ключом из репозитория, поэтому новые сборки ставятся поверх старых без потери данных.

## Проверка на телефоне

1. Откройте Widgetly, выберите шаблон, нажмите **Сохранить**, затем **На экран** и подтвердите.
2. Либо долгое нажатие на рабочем столе → Виджеты → Widgetly → выберите дизайн в списке.
3. Вкладка **Погода**: выберите город (или геолокацию) и нажмите «Обновить сейчас».
4. Вкладка **Погода → Состояние** показывает время последней отрисовки, размер bitmap и ошибки. Если что-то не так, пришлите этот блок и `adb logcat`.

## Разработка в браузере (порт 8080)

```bash
cd web
npm install
npm run dev        # http://localhost:8080, с телефона: http://<IP-компьютера>:8080
```

В браузере работает весь редактор. Вместо нативного плагина подключается заглушка на `localStorage`
(`web/src/bridge/web.ts`); закрепление виджета и список активных виджетов доступны только в приложении.

### Live-reload в APK

Запустите **Actions → CI → Run workflow** и укажите `dev_url`, например `http://192.168.1.50:8080`.
Получится debug-APK, WebView которого грузит ваш dev-сервер: правки веба видны на телефоне сразу.
Cleartext-трафик разрешён только в debug (`android/app/src/debug/AndroidManifest.xml`).
Не используйте такой APK как обычный: без запущенного dev-сервера он ничего не покажет.

## Локальная сборка (необязательно)

Нужны Node 22+, JDK 21, Android SDK (platform 36, build-tools).

```bash
cd web && npm ci && npm run build && npx cap sync android
cd ../android && ./gradlew assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

## Релиз

1. Создайте keystore: `keytool -genkeypair -v -keystore release.jks -alias widgetly -keyalg RSA -keysize 2048 -validity 36500`
2. Положите в **Settings → Secrets → Actions**: `RELEASE_KEYSTORE_B64` (`base64 -w0 release.jks`), `RELEASE_STORE_PASSWORD`, `RELEASE_KEY_ALIAS`, `RELEASE_KEY_PASSWORD`.
3. Сделайте резервную копию keystore вне GitHub. Потеря ключа = невозможность обновлять приложение.
4. Тег `v0.1.0` → workflow `Release` соберёт подписанные APK и AAB и приложит их к GitHub Release.

## Известные ограничения

- Виджет рисуется как картинка и обновляется раз в минуту не-будящим будильником. При выключенном экране или в Doze время обновится при пробуждении; точность до секунды не гарантируется.
- Шрифты системные (Roboto-семейство на Android). В браузере без Roboto вид слегка отличается от виджета.
- Эмодзи-иконки погоды зависят от системного шрифта эмодзи.
- Геолокация только приблизительная и без фонового разрешения: в фоне используется последняя известная точка. Если её нет, выберите город.
- На Xiaomi, Huawei, Samsung и др. может понадобиться отключить ограничения батареи (кнопка в разделе «Погода»).
- Интерфейс редактора только на русском; язык дат и погоды в виджете выбирается в дизайне (RU/EN).
- Иконка приложения стандартная от Capacitor.
