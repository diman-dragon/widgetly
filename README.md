# DataLaw Widgetly — виджет часов, погоды и календаря (Capacitor 8)

Один настраиваемый виджет для рабочего стола Android: слева фон с часами, днём недели и датой, **под датой — две строки событий календаря**,
справа погода и прогноз на 3 дня. Редактор — HTML/JS (`www/`), виджет, обновления и запросы — нативный Java (`native/android/`).

## Что умеет
- **Календарь под датой:** две строки; событий больше двух — листаются по кругу (каждые 4 с, средствами самого виджета); нет событий — блок скрыт. Окно: сегодня / 2 / 3 / 7 дней. Доступ `READ_CALENDAR` запрашивается самим блоком (при включении или кнопкой) и нужен только ему; в блоке выбираются календари, которые показывать; цвет точки — цвет календаря.
- **Тапы:** часы → приложение «Часы» (будильники), события → «Календарь», остальное → редактор. Нет подходящего приложения — открывается DataLaw.
- **Кнопка «Добавить на рабочий стол»:** если виджет уже стоит, превращается в «Обновить виджет» и ничего не дублирует.
- **Темы приложения:** светлая светло-коричневая, тёмная AMOLED (чёрный фон), либо системная.
- **Имя и иконка:** DataLaw Widgetly; иконка — логотип DataLaw на тёмно-синем + жёлтый круглый значок «солнце и облако» (адаптивная + монохромная для Android 13+). Бренд DataLaw: логотип в «О приложении» и на заставке.
- **Настройки виджета:** прозрачность, скругление, рамка, фон слева (закат / ночь / своё фото / без), затемнение, ширина левой части, цвета; шрифт (20 штук: без засечек, **с засечками**, моно, декоративные; встроенные — Lora, IBM Plex Serif, Poiret One, Jura, Tektur, JetBrains Mono, Geist Mono), размер и цвет для часов, дня недели, даты, календаря, погоды; форматы; часовой пояс часов.
- **Погода:** Open-Meteo (по умолчанию) и MET Norway — без ключей; OpenWeatherMap и WeatherAPI.com — со своим API-ключом. Прогноз 0–3 дня, °C/°F, поиск города.
- Предпросмотр 5×3 (по умолчанию), 4×3, 5×2, 4×2 — рисуется тем же кодом, что и сам виджет.

## Как обновляется
- **Часы** — системный `TextClock`, каждую минуту сами, без секунд.
- **Дата и день недели** — раз в сутки, на первом «тике» с включённым экраном после смены дня.
- **Погода** — не чаще раза в 6 часов (можно 12/24); один запрос приносит и текущую погоду, и прогноз.
- **Календарь** — перечитывается на «тике» (раз в 5 минут) при включённом экране.
- При выключенном экране ничего не обновляется: «тик» — неточный не-wakeup `AlarmManager`.

## Сборка (только VS Code + git)
1. `git add -A`, коммит, `git push` в `main`.
2. **Actions → Android build** → артефакт `datalaw-debug-apk`. Все сборки подписаны одним ключом из репозитория (`native/android/debug.keystore`) и имеют растущий `versionCode`, поэтому **новая сборка ставится поверх установленной — данные сохраняются**. Один раз, при переходе с более ранних сборок (они подписывались случайным ключом), приложение нужно удалить.
3. Для Google Play — секреты `KEYSTORE_B64`, `KEYSTORE_PASSWORD`, `KEY_ALIAS`, `KEY_PASSWORD` → артефакт `datalaw-release-aab`. Подробности: `docs/PLAY_STORE.md`.

Локально (Node 22+, JDK 21, Android SDK): `npm install && npm run android:setup && cd android && ./gradlew assembleDebug`.
Проверка вёрстки в браузере: `npm run web` (картинку виджета рисует только Android-версия).

## Перед публикацией
- Вписать публичный URL политики в `PRIVACY_URL` (`www/js/app.js`), подставить дату и e-mail в `docs/PRIVACY_POLICY.md`.
- Убедиться, что `appId` (`capacitor.config.json`, сейчас `com.widgetstudio.app`) окончательный: после публикации менять нельзя, а при смене приложение ставится отдельно от прежнего.

## Ограничения
- На Android 7.x встроенные шрифты в самом виджете заменяются близкими системными (в редакторе и превью — настоящие).
- Тап по виджету вне часов и событий открывает приложение.
- Блок часов один (системный `TextClock`); мировое время — через часовой пояс блока.
- Шрифты — системные семейства Android. Свой `.ttf`: нужен `res/font`, расширение `Renderer.tf()` и ещё один `TextClock` в `widget_root.xml`.
