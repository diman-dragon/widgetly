# Часы и погода — Android-виджет

1. Создайте репозиторий на GitHub, залейте папку (ветка `main`).
2. Вкладка **Actions → Build APK** (запускается на push или вручную).
3. По окончании скачайте артефакт `ClockWeather-apk` → `app-release.apk`, установите на телефон.
4. Долгий тап по рабочему столу → Виджеты → «Часы и погода».

Погода: Open-Meteo (без ключа). Город вводится вручную, геолокация не нужна.
